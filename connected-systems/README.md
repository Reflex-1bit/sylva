# Connected systems

A research report that connects four things that were written separately:

1. **Sylva** (this repository): agroforestry decision support for farms moving to regenerative, tree-integrated systems, with a low-cost soil node for verification.
2. **ReachOut** ([Aarrushh/reachout](https://github.com/Aarrushh/reachout)): a hyperlocal demand router. You say what you need; shops within two kilometres that have it in stock answer.
3. **The biomimicry intelligence firm** (a pitch): map the traits of local species to industry problems, sell the insight, send funding back to the reserves.
4. **The consciousness thesis** (an essay in progress): attention algorithms erode self and empathy; the counterforce is connection, nature, and doing rather than consuming.

The folder name is a placeholder. It is written so it can be lifted into its own repository unchanged.

## How claims are tagged

Every factual claim carries one of three tags.

- **[Certain]**: read directly from a repository file or a primary source during this session.
- **[Likely]**: consistent across several secondary sources, but the primary source was not read.
- **[Guessing]**: an estimate or inference. Verify before relying on it.

Sources older than two years carry their year in the text. Nothing here is coded. The report is the deliverable.
